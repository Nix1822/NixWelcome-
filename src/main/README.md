# NixAnnounce

Broadcasts messages from `config.yml` automatically, one after another, on a timer.

- Interval, prefix and messages are configurable
- `&` color codes supported
- `/nixannounce reload` (permission `nixannounce.admin`)

Build: `mvn clean package` -> `target/NixAnnounce-1.0.0.jar`
Requires Java 21 and Paper 1.21.4.
